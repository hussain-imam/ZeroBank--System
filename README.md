# ZeroBank - System
A Simple and Clean Python Banking System.
# Features
- create new account
- deposit money
- withdraw money
- check balance
- view account detail
- data saved in json
  ## Files
  -main.py - main program to run
  -bank.py - bank logic
  -account.py -account class
  -person.py - person class
  -accounts.json - saved accounts data
  ##  How to Run
  python main.py
